# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2025-03-19

### Added

- Python curriculum: 86 lessons across Beginner, Intermediate, Practical, Advanced, and Expert stages
- JavaScript curriculum: 82 lessons across Beginner, Intermediate, Practical, Advanced, and Expert stages
- In-browser Python execution via Pyodide
- In-browser JavaScript execution via sandboxed iframe
- AI hints via Anthropic API (claude-sonnet-4)
- API key storage via OS keychain (safeStorage)
- Progress tracking, XP system, and achievements
- Per-language notes
- External curriculum folder support for adding new languages without rebuilding
- Windows and Mac installers via electron-builder
